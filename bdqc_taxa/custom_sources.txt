
This is a custom source for bdqc_taxa.
It contains custom taxa list as tables in a sqlite database with FTS5 enabled for autocomplete.

TABLE bryoquel

Description: 
    This file was generated on 2022-09-21 from the Bryoquel taxonomy file.
    The file was downloaded from http://societequebecoisedebryologie.org/Bryoquel.html on 2022-09-21.
    The last version of the bryoquel xlsx file is from 2022-09-12`.
    The file was parsed using the script `scripts/parse_bryoquel.py`.
    The file was parsed using the script parse_bryoquel.ipynb.

Columns:
    The file contains a pandas dataframe with the following columns:
    id: the Bryoquel IDtaxon
    scientific_name: Noms latins acceptés du taxon, sans auteur
    taxon_rank: Taxon rank
    genus: Taxon genus
    family: Taxon family
    clade: Taxon clade
    canonical_full: Noms latins acceptés du taxon, avec auteur
    authorship: Auteur obtenu de Noms latins acceptés
    vernacular_name_fr: Noms français acceptés
    vernacular_name_en: Noms anglais acceptés


TABLE cdpnq_odonates

Description: 
    This file was generated from the CDPNQ odonates data file.
    The file was obtained from Anouk.Simard@mffp.gouv.qc.ca on May 24, 2022
    The last version of the bryoquel xlsx file is from 2022-09-12`.
    The file was parsed using the script `scripts/make_cdpnq_odonates.py`.

Columns:
    name: scientific name
    valid_name: valid scientific name
    rank: rank of the taxa
    synonym: boolean indicating if the name is a synonym
    author: author of the scientific name
    canonical_full: canonical full name
    vernacular_fr: vernacular name in French
    vernacular_fr2: vernacular name in French from Natureserve


TABLE cdpnq_vertebrates

Description: 
    This file was generated from the Liste de la faune vertébrée du Québec (LFVQ) Data file LFVQ_25_03_2026.xlsx.
    The file was obtained from Données Québec on 2026-11-02.
    The last version of the file is from 2026-04-13.
    The file was parsed using the script `scripts/make_cdpnq_vertebrates.py`.

Columns:
    source_dataset_id: ID of the source dataset
    name: scientific name
    valid_name: valid scientific name
    rank: rank of the taxa
    synonym: boolean indicating if the name is a synonym
    author: author of the scientific name
    vernacular_fr: vernacular name in French
    vernacular_en: vernacular name in English
    genus: genus of the taxa
    species: species of the taxa
    origin: origin of the taxa (Indigène, Exotique, Inconnu/Non déterminé)
    s_rank: scientific rank of the taxa (e.g. S1, S2, S3, etc.)

Notes:
    The entries have no recorded author.
    Species that have only one infra-taxon (subspecies, or population when there is no subspecies)
    are synonyms of that infra-taxon. All Quebec observations of the species are assumed to be the
    infra-taxon. Species listed themselves in the LFVQ are remapped only if the infra-taxon has a status
    in the list of the species followed by the CDPNQ (liste-especes-suivies-CDPNQ.xlsx).
    ie. Nerodia sipedon -> Nerodia sipedon sipedon, Rangifer tarandus -> Rangifer tarandus caribou,
    Desmognathus ochrophaeus -> Desmognathus ochrophaeus pop. 2, Osmerus mordax -> Osmerus mordax pop. 1,
    but not Loxia curvirostra (Loxia curvirostra percna has no status)
    Falco peregrinus, Falco peregrinus anatum and Falco peregrinus tundrius -> Falco peregrinus pop. 1

TABLE eliso_invertebrates

Description: 
    This file was generated on 2026-05-12 from Eliso's Répertoire des noms d'invertébrés du Québec (2025) file.
    The file was downloaded from https://www.repertoirenature.org/documents on 2026-05-12.
    The file was parsed using the script `scripts/make_eliso.py`.


Columns:
    The file contains a pandas dataframe with the following columns:
    taxa_name: Scientific name of the taxon
    vernacular_fr: French vernacular name of the taxon
    taxa_rank: Taxon rank
    Embranchement: Phylum
    Classe: Class
    Ordre: Order
    Famille: Family
    Genre: Genus
    Espèce: Species


Notes:
    The entries have no recorded author.
    The entries may contain comments in parentheses that are kept as is but may prevent matching.


TABLE vascan_remap

Description:
    This file was generated from the VASCAN Darwin Core Archive vascan_dwc_03-11-2026.
    The archive was obtained from https://data.canadensys.net/vascan/checklist on 2026-11-03
    (region: Quebec; statuses: native, introduced, ephemeral, doubtful, extirpated, excluded;
    ranks: species, subspecies, variety, hybrids included).
    The file was parsed using the script `scripts/make_vascan_remap.py`.
    Species (and intermediate infra-taxa) that have exactly one infra-taxon present in Quebec
    are mapped to that infra-taxon. All Quebec observations of the species are assumed to be the infra-taxon.
    Only the remapped taxa are listed.
    Manual remaps are added for taxa with no Quebec distribution in VASCAN, while the CDPNQ lists the
    infra-taxon in Quebec and it is the only infra-taxon of the species in VASCAN
    (Cirsium scariosum -> Cirsium scariosum scariosum). Their n_infra_* columns are 0.
    Infra-taxa counted as present in Quebec: doubtful, ephemeral, extirpated, introduced, native, and the infra-taxa
    on the list of the species followed by the CDPNQ (liste-especes-suivies-CDPNQ.xlsx, any situation)
    whatever their VASCAN status (ie. Symphyotrichum lanceolatum subsp. lanceolatum var. interior).

Columns:
    taxon_id: VASCAN taxonID of the taxon to remap (species or intermediate subspecies)
    name: canonical name of the taxon to remap, without authorship nor rank marker (ie. Cakile edentula edentula)
    rank: rank of the taxon to remap
    parent_id: VASCAN taxonID of the parent of the taxon to remap, empty for species
    valid_taxon_id: VASCAN taxonID of the infra-taxon to remap to
    valid_name: canonical name of the infra-taxon, without authorship nor rank marker (ie. Arnica griscomii griscomii)
    valid_rank: rank of the infra-taxon (subspecies or variety)
    valid_authorship: authorship of the infra-taxon
    valid_qc_status: VASCAN status of the infra-taxon in Quebec
    n_infra_listed_qc: number of lowest-level infra-taxa listed for Quebec, any status
    n_infra_counted_qc: number of those counted as present in Quebec (always 1, 0 for manual remaps)
    vascan_consulted: date the VASCAN archive was generated

Notes:
    Match on VASCAN taxon IDs, which are the record IDs returned by Global Names for VASCAN (data source 147).
    The hierarchy of an infra-taxon is rebuilt by following parent_id between the rows that share its
    valid_taxon_id (ie. 3935 <- 3936 <- 9885 for Cakile edentula edentula edentula).
